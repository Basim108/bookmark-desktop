# Changelog

What changed in each released version, written for the people who use Bookmark
Desktop. The extension shows the entry for the version it is running, so keep
these entries short, plain, and about what a user will notice — not about how it
was built.

The account for contributors lives in the GitHub release for each version, which
is generated from the commit history and carries the full detail, dependency
updates included. This file is the other half of that split, and never mentions
a dependency bump.

**Entry format** — the build parses this, so the shape matters:

```markdown
## <version>

> An optional heads-up: one sentence, only when users will notice something
> disruptive. Say what they will see and why it is fine.

- A change, written for a user
- Another change

An optional closing sentence rolling up the bug fixes. Never enumerate them.
```

Keep the bullet list to roughly five entries. If a release did more than that,
it did more than a user wants to read about.

## 1.1.0

> Your icons settle into place once after this update, and stay put from then
> on — nothing has been lost.

- Turn pages with a flick of your mouse wheel, without reaching for the arrows
- Bring your uTab bookmarks across in a single step, with a clear report of
  anything that needed your attention
- Drop a folder between any two rows to put your sidebar in exactly the order
  you want
- Carry a bookmark across pages in one drag, with the canvas turning as you go
- Find your last open folder already waiting whenever you open a new tab
- Copy or move a bookmark to any folder from its gear menu, with folder search
  when the tree is long

Alongside these, a number of fixes and refinements to icon layout, grid sizing,
and the settings windows.

## 1.0.0

- Open a new tab onto a desktop of your own bookmarks, arranged as icons on a
  grid you control
- Keep your folders in a sidebar and click one to bring its bookmarks to the
  front
- Drag any icon where you want it and find it there again, in every tab and
  after every restart
- Give any bookmark or folder its own picture, or set a background image for
  the whole desktop
- Take your whole arrangement with you by exporting it, and put it back on
  another machine by importing it
